Model Design

  • Type: 3-layer GAT (Graph Attention Network)
  • Task: Graph-level classification (one logit per snapshot)
  • Hidden dim: 128
  • Attention heads: 4 (first 2 layers), 1 (final layer)
  • Activation: ReLU
  • Dropout: 0.2
  • Pooling:
  • Classifier:
  • Continual learning: Rehearsal buffer 10% with reservoir sampling, λ=1.0

6. Bottleneck Analysis — All Settled

Bottleneck 1: CM vs Metrics "Mismatch" in Prometheus

Symptom: Confusion matrix shows FN=5 but Recall=1.0 in the metrics block.

Resolution: NOT a bug. The CM is computed at the saved threshold (0.029418677743524312). The best-F1 metrics are at a threshold 2.86e-8 lower (0.029418649151921272). Both display as "0.0294" at 4-digit precision. The 5 FN positives have probabilities in that tiny gap. The script is correct; the display is misleading.

SETTLED

Bottleneck 2: Recall@1%FPR Broken with Tiny Negative Class

Symptom: Prometheus recall@1%FPR = 0.750 seems low given AUC-PR=0.991.

Resolution: With only 2 negative samples, FPR can only be 0%, 50%, or 100%. A 1% FPR target is impossible. The 0.750 value comes from quantile interpolation and is a noisy, unreliable estimate. This metric is uninformative at this sample size. TG-Detect doesn't have this problem — it has 214,516 negatives, so 1% FPR = 2,145 FP, a meaningful budget.

SETTLED

Bottleneck 3: AUC-PR Gap (0.991 vs 0.998)

Symptom: Prometheus AUC-PR=0.991 vs TG-Detect AUC-PR=0.998 — is the gap real?

Resolution: The gap is real but expected due to sample size. Prometheus has 50 test graphs (48 positive, 2 negative). TG-Detect has 216,347 test edges (1,831 positive). With 50 samples, AUC-PR has high variance — a single misranked pair shifts it noticeably. With 216K samples, AUC-PR is stable. The gap does not indicate a quality difference; it's a sample-size artifact.

SETTLED

Bottleneck 4: Recall Gap (0.896 vs 0.993)

Symptom: Prometheus misses 10% of positive windows; TG-Detect misses 0.7% of positive flows.

Resolution: Real gap, but the models answer different questions. Prometheus at graph level: a window with 1 malicious flow out of 100 is "positive" — if the model misses that one flow, the whole window is FN. TG-Detect at edge level: it evaluates each flow independently. The recall gap partly reflects granularity, not just quality. Also, Prometheus was trained for only 5 epochs vs TG-Detect's 15-epoch convergence.

SETTLED

Bottleneck 5: Models Answer Different Questions

Symptom: How to compare graph-level and edge-level models fairly?

Resolution: They are not directly comparable at the same granularity. Prometheus says "this window is suspicious" (50 test units). TG-Detect says "this flow is malicious" (216K test units). Operationally, edge-level is more actionable — an operator can block a specific flow but not a whole window. The comparison is valid only at the AUC level (ranking quality), not at the F1/accuracy level (which depends on threshold and granularity).
